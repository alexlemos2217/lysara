## 🌙 La historia

Una noche, **el Corazón de la Bruma** dejó de latir. Los árboles perdieron sus recuerdos, las ruinas quedaron ocultas y las sombras ocuparon los senderos.

**Iri**, una joven guardiana, escucha una última llamada desde el santuario. Para devolverle la luz al bosque debe encontrar **tres ecos perdidos** y abrir la puerta sellada.

> *«El silencio no es la ausencia de vida. Es el bosque conteniendo la respiración».*

## ✨ Qué incluye esta demo

| Sistema | Características |
| --- | --- |
| 🎮 Plataformas | Movimiento con inercia, salto de altura variable, *coyote time* y *jump buffer* |
| ⚡ Impulso | Dash aéreo con efecto luminoso y recuperación al aterrizar |
| ⚔️ Combate | Ataque cuerpo a cuerpo, enemigos patrullando, vida, daño y retroceso |
| 🌲 Mundo | Escenario horizontal extenso, plataformas, abismos, ruinas y fondos de múltiples capas |
| 💎 Exploración | Tres ecos coleccionables, textos narrativos y un santuario para completar el capítulo |
| 🕯️ Progreso | Altares de control, recuperación de vida y guardado en el navegador |
| 🎨 Presentación | Paisajes generados por Canvas, niebla, brillos, animaciones, partículas y desplazamiento de cámara |
| 📱 Controles | Teclado y botones táctiles en dispositivos compatibles |
| 🔊 Audio | Efectos sencillos sintetizados con Web Audio, sin descargas de sonido |

## 🕹️ Controles

| Acción | Teclado |
| --- | --- |
| Caminar | `A` / `D` o `←` / `→` |
| Saltar | `Espacio`, `W` o `↑` |
| Impulso | `Shift` o `K` |
| Ataque | `J` o `X` |
| Interactuar | `E` |
| Pausa | `Esc` |

**Consejo:** mantené presionado el salto para llegar más alto y combiná salto + impulso para cruzar los abismos. Para una mejor experiencia móvil, usá el celular horizontalmente.

## 🚀 Cómo jugar

1. Descargá o cloná el repositorio.
2. Abrí `index.html` en un navegador moderno.
3. Elegí **Comenzar aventura**, leé el prólogo y explorá.


## 🛠️ Tecnologías

- HTML5 Canvas 2D — dibujado del mundo y del personaje.
- JavaScript — física, colisiones, combate, cámara, estado y partículas.
- CSS — interfaz adaptable y controles táctiles.
- Web Audio API — efectos de sonido.
- LocalStorage — progreso guardado localmente.

## ⚠️ Estado y uso

Este proyecto es un **prototipo técnico y artístico**, no un videojuego listo para vender ni una reproducción de otros títulos. **LYSARA** es un nombre de trabajo sujeto a verificación de disponibilidad antes de cualquier lanzamiento comercial. No utiliza personajes, ilustraciones ni recursos de Hollow Knight o Celeste.

Diseño y código inicial preparados como base de un proyecto original para seguir desarrollando y personalizando.
